# The Digital Detective

## About This Project

This repository is part of my Diwali Independent Learning Assignment, titled *The Digital Detective*.

Through this assignment, I will explore how computers work, learn to use the Terminal, understand how operating systems manage files and programs, and get familiar with Git and GitHub. I will also work with Python and learn how computers represent numbers and text.

## Mission Index

I have divided the assignment into different missions so that I can complete and document my learning step by step.

| Mission | Topic |
|---|---|
| Mission 0 | Repository and Workspace Setup |
| Mission 1 | Computer Fundamentals and IPOS |
| Mission 2 | Terminal and File Management |
| Mission 3 | Operating Systems and Processes |
| Mission 4 | How Programs Run |
| Mission 5 | Number Systems and Data |
| Mission 6 | Git and GitHub |
| Mission 7 | Computer Networks |
| Mission 8 | Final Report and Submission |

## How I Have Organised This Repository

Each mission has its own folder and README file where I will record the tasks, commands, observations and things I learn.

I will complete the missions in order and maintain separate Git commits for each completed mission. This will also help me keep track of my progress.

## My Goal

My goal is not just to finish the assignment, but to understand what I am doing and become more comfortable working with my computer, Terminal, Python and GitHub.

## My Learning

Through this assignment, I have learned:

- How computers represent and process information using binary and other number systems.
- How to use Terminal commands and Python programs to explore and work with files.
- How Git tracks changes and how GitHub helps people share and collaborate on projects.
