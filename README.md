# The Digital Detective 🔍

### Diwali Independent Learning Assignment

Welcome to **The Digital Detective**, a mission-based exploration of computer systems, programming, operating systems, number systems, Git, GitHub and computer networks.

This repository documents my learning journey through eight missions, combining theoretical concepts with practical activities using Terminal, Python and GitHub.

The goal of this assignment was to understand how computers work, experiment with essential development tools and build confidence in solving technical problems independently.

## 🐍 Running the Number Converter

As part of Mission 05, I created a Python program that converts a positive decimal number into its binary and hexadecimal representations.

**Requirements:**
- Python 3 installed on your system.
- Terminal or command-line access.

**Steps to run:**

Clone the repository:

```bash
git clone https://github.com/bhavyarajsinh1510/digital-detective-8405.git
```

Navigate into the repository:

```bash
cd digital-detective-8405
```

Open the Mission 05 folder:

```bash
cd mission-05-numbers-data
```

Run the Python program:

```bash
python3 number_converter.py
```

**Example output:**

```text
Enter a positive decimal number: 25
Decimal: 25
Binary: 11001
Hexadecimal: 19
```
