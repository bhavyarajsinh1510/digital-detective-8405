## 5. Running the Number Converter

The number converter is located inside the `mission-05-numbers-data/` folder.

To run it, open the repository in Terminal and execute:

```bash
cd mission-05-numbers-data
python3 number_converter.py
```

The program accepts a positive decimal integer and displays its binary and hexadecimal representations.

Example:

```text
Enter a positive decimal number: 25
Decimal: 25
Binary: 11001
Hexadecimal: 19
```
