## 3. Work Completed

### Task 1.1 — Understanding IPOS

I chose the activity of typing and saving a document on my computer.

| Stage      | What happens?                                                          | Hardware / Component |
| ---------- | ---------------------------------------------------------------------- | -------------------- |
| Input      | I type text using the keyboard.                                        | Keyboard             |
| Processing | The computer processes the typed information and handles the document. | CPU and RAM          |
| Output     | The document appears on the screen.                                    | Display              |
| Storage    | The document is saved so I can open it later.                          | SSD                  |

The IPOS cycle stands for Input, Processing, Output and Storage. These four stages explain how a computer receives information, works on it and provides or saves the result.

### Task 1.2 — Hardware and Software

Hardware refers to the physical parts of a computer that we can touch, whereas software consists of the programs and instructions that make the computer perform different tasks.

**Hardware examples**

| Item     | Classification | Purpose                                   |
| -------- | -------------- | ----------------------------------------- |
| Keyboard | Hardware       | Used to enter text and commands.          |
| Trackpad | Hardware       | Used to control the pointer.              |
| Display  | Hardware       | Shows text, images and other information. |
| SSD      | Hardware       | Stores files and applications.            |

**Software examples**

| Software           | Classification            | Purpose                                          |
| ------------------ | ------------------------- | ------------------------------------------------ |
| macOS              | Operating system software | Manages the computer and its resources.          |
| Google Chrome      | Application software      | Used to browse websites.                         |
| Visual Studio Code | Application software      | Used to write and edit code.                     |
| Activity Monitor   | Utility software          | Helps view running processes and resource usage. |

### Task 1.3 — Computer Systems Around Me

Computer systems are not limited to laptops and phones. Many everyday devices use computers to perform specific tasks.

| System         | Main Purpose                                    | One Input             | One Output                  |
| -------------- | ----------------------------------------------- | --------------------- | --------------------------- |
| ATM            | Allows people to perform banking transactions.  | Card or PIN entry     | Cash or transaction receipt |
| Smart TV       | Plays television programmes and online content. | Remote control        | Picture and sound           |
| Traffic signal | Controls the movement of vehicles.              | Timer or sensor input | Traffic lights              |
